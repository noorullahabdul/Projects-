# Recovered engineering references

These are input/reference materials from the independent powertrain archives
listed in docs/RECOVERY_CATALOG.md. They are not the current application.

- ltspice_physical: component/coil proxy model and static package validator.
- ltspice_complete: alternate native schematic/netlist model.
- simulation: earlier SPICE exploration models.
- simulink: MATLAB/Simulink generation and analysis scripts.
- requirements, architecture, design, hardware, safety, hil, prototype:
  engineering planning and design records.
- verification: historical test procedures and DVP&R plans.

Original internal filenames/links may refer to the historical portfolio layout
or omitted legacy result files. Use the current Python reports for current
computed outcomes. The full originals are retained in recovered_sources for
private recovery; they contain historical claims that have not been accepted as
current verification evidence.

No native EDA tool execution, supplier model correlation, bench result,
functional-safety assessment or certification is implied.
