## Description to adapt after running the project

I am developing a Python validation tool for an 800 V EV DC-link. It combines
precharge/discharge calculations, a contactor supervisor, synthetic fault
injection, component/sensor corner analysis and CSV telemetry diagnostics.
It produces machine-readable evidence, a standalone engineering report and
a local run ledger. It also contains my independently recreated LTspice and
MATLAB/Simulink design references. I use AI assistance to develop and review
the code, and I verify results using regression tests and electrical invariants.
