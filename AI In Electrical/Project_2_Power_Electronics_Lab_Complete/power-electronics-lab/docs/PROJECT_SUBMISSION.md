# Project submission notes

Suggested repository name: power-electronics-lab

## Description to adapt after running the project

I am developing a Python engineering workbench for a 48 V-to-12 V buck
converter, an OBC PFC/LLC stage and a 150 kW traction inverter. The project
contains a numerical LC transient model, waveform validation, explicit loss
and thermal calculations, a resonant-tank frequency solver, and signed
motoring/regeneration power maps. I use AI assistance for code development,
then verify electrical invariants, edge cases, fault detection and numerical
convergence with regression tests.

## Actual present status

This is a new tested software extension of recovered independent powertrain
studies. Samples are synthetic and assumptions are documented. Native
simulation inputs are included, but no bench or vendor-tool run is claimed.
The repository has not been published by this bundle-generation task.

Planned work includes measured-data integration, PWM delay, calibrated device
loss models, field weakening and LLC commutation-charge validation.
