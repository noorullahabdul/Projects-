# Requirements and Verification Matrix

| ID | Requirement | Verification |
|---|---|---|
| OBC-001 | Operate from 360–440 V line-to-line AC | Automated sweep |
| OBC-002 | Support 500–800 V battery range | Automated sweep |
| OBC-003 | Deliver up to 30 kW | Calculation/sweep |
| OBC-004 | Estimated full-power efficiency ≥ 94% | Loss model |
| OBC-005 | Output ripple ≤ 2% | Reduced-order ripple model |
| OBC-006 | Evaluate ±10% Lr and Cr tolerance | Corner sweep |
| OBC-007 | Evaluate 80–160 kHz switching range | Corner sweep |
| OBC-008 | Flag insufficient dead time/ZVS proxy | Automated limit check |

This matrix is portfolio evidence, not a certification plan. PF/THD, conducted emissions, isolation, thermal cycling, and safety compliance require higher-fidelity models and laboratory measurements.
