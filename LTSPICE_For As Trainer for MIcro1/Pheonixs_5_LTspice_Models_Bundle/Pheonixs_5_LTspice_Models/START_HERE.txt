PHEONIXS — FIVE SELECTED LTSPICE MODELS

1. Extract the entire ZIP. Keep each model folder intact.
2. On your Windows LTspice computer, double-click OPEN_MODELS.bat.
3. Select a model, then press Run in LTspice. Load Model.plt if needed.
4. Each model folder contains Model.asc, Model.plt, local symbols/libraries,
   README.md, a trace list and preserved original source files.

01 — LT8584 active cell balancer

03 — LT8304 isolated dual-secondary flyback
04 — LTC7851 four-phase VRM load transient
